NSE F&O PCS SCANNER - QUICK START GUIDE
================================================================================

WHAT WAS CREATED:
  ✅ Standalone Python scanner (simple_scanner.py)
  ✅ Telegram integration for automated notifications
  ✅ Technical indicator calculations (RSI, MACD, ADX, etc.)
  ✅ Pattern detection (breakouts, support/resistance)
  ✅ CSV export of results

REQUIREMENTS:
  - Python 3.7+
  - pandas, numpy, yfinance, requests
  - Telegram bot token (optional)

================================================================================
SETUP IN 3 STEPS:
================================================================================

1. GET TELEGRAM CREDENTIALS (Optional but recommended)

   Bot Token:
   - Open Telegram and message @BotFather
   - Send /newbot and follow prompts
   - Copy the token you receive

   Chat ID:
   - Message @userinfobot on Telegram
   - Note your User ID shown in the response

2. SET ENVIRONMENT VARIABLES

   In your terminal:
   export TELEGRAM_BOT_TOKEN="your_bot_token_here"
   export TELEGRAM_CHAT_ID="your_chat_id_here"

   For persistent setup, add to ~/.bashrc or ~/.bash_profile

3. INSTALL DEPENDENCIES (if needed)

   pip install pandas numpy yfinance requests

Quick Scan (30 stocks):

FILTER CRITERIA (Default):
================================================================================

RSI:           30 - 75  (healthy momentum for short puts)
ADX:           >= 20    (trend confirmation)
Volume:        >= 1.2x  (above average volume)
Lookback:      20 days  (consolidation period)

  Edit simple_scanner.py in the SimplePCSScanner.check_basic_criteria() method

================================================================================
TROUBLESHOOTING:
================================================================================

No stocks found:
  → Try: python3 simple_scanner.py --all
  → Wait a few minutes (data sync delay)
  → Check network: curl https://finance.yahoo.com

"Telegram credentials not set":
  → Normal in dry-run mode - results still shown
  → Set environment variables if you want Telegram notifications
  → Results are always saved to CSV file

Connection errors:
  → May need proxy/VPN configuration
  → Try again - yfinance sometimes has rate limits
  → Check network connectivity
